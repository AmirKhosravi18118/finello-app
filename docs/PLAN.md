# PLAN — Finello

**Finello** (نام کاری قبلی: RatenReminder) — اپ یادآور قسط‌های ماهانه + مدیریت خرج + آماده‌سازی مالیات، برای مهاجران و دانشجویان آلمان. سه‌زبانه fa/de/en، RTL/LTR.

- مخاطب P1: دانشجوی مهاجر در آلمان (پرداخت قسط با SEPA دستی) → P2: مهاجران → P3: هر کاربر EUR.
- کسب‌وکار: Freemium (یادآور/خرج رایگان، مالیات/مقایسه پیشرفته Premium).
- تحلیل بازار: `docs/MARKET_ANALYSIS.md` — برنده شدن در نیش، نه رقابت همه‌جانبه با Finanzguru.

## Stack (فاز پروتوتایپ)
- `app/`: Vite 6 + React 19 + TypeScript strict + Tailwind v4 (توکن‌های CSS در `src/index.css`).
- i18n: موتور اختصاصی سبک (`src/i18n/`) — بدون i18next. عدد/ارز/تاریخ با Intl.
- دیتا: `src/data/demo.ts` (تیپ‌دار) + localStorage برای تنظیمات؛ بدون بک‌اند.
- تست: Vitest (منطق خالص: موتور i18n، محاسبات) — بدون تست CRUD نمایشی.
- نمودار: SVG دستی — بدون کتابخانه چارت.

## CI / بستر (بهینه‌سازی فضا و هزینه)
- GitHub Actions فقط (runner اوبونتو رایگان-سهمیه‌ای). **بدون Docker و بدون رجیستری ایمیج در این فاز** — چیزی برای میزبانی وجود ندارد؛ داکر در V2 همراه بک‌اند وارد می‌شود (ADR-002).
- کش npm با کلید lockfile؛ آرتیفکت فقط هنگام شکست، retention ۳ روز.
- اکشن‌ها با SHA پین می‌شوند (§4.1 هنداف).

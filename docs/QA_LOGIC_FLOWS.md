## باگ منطقی کلیدی (جزئیات فنی)
- **باگ A — مود شیت پول:** `AddMoneySheet` مود را فقط در `reset()` (هنگام بستن) با `initialMode` همگام می‌کند، نه هنگام باز شدن (`src/components/AddMoneySheet.tsx:24`). چون کامپوننت همیشه مونت است، اولین باز شدن «درآمد» (از منوی + یا دکمه درآمد) شیت را در مود «هزینه» با عنوان هزینه‌ای باز می‌کند؛ اگر کاربر ادامه دهد، مبلغ به‌صورت هزینهٔ منفی ثبت می‌شود. اصلاح: `useEffect(() => { if (open) { setMode(initialMode); setName(''); setAmount(''); } }, [open, initialMode])`.
- اعلان import بانک فقط از TransactionsScreen صادر می‌شود، نه از دکمه دریافت Konten — همان اکشن، دو رفتار.

## حکم نهایی
اسکلت جریان‌ها سالم و منسجم است: ورود→راه‌اندازی→تور→خانه کاملاً هدایت‌شده، حلقهٔ دسته‌بندی‌نشده‌ها (بج زنگ → مرکز اعلان → تراکنش‌ها) درست بسته می‌شود و همهٔ CRUDها به استور واقعی می‌رسند. اما **۴ جریان مسدود/داروی بی‌اثر** (باگ A، Import بی‌بانک، افزودن قسط در تقویم، تاگل همگام‌سازی) و **یک وعدهٔ محیطی برآورده‌نشده** (یادآور روزانه) باید پیش از انتشار عمومی اصلاح شود. اولویت: باگ A (خطر ثبت اشتباه درآمد/هزینه) > Import بی‌بانک > تقویم/تاگل‌ها.
